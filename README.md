# AI App Generator

基于 Atoms 的智能应用生成器。

## 在线体验

https://1fufev4.pub.atoms.world

## 项目简介

一个 AI Native 的网页应用生成器。用户用自然语言描述想要的应用，智能体实时调用大模型生成完整可运行的代码，并直接在右侧预览区渲染。交互形态参考 Atoms 本身：左侧对话输入，右侧可视化结果，支持多轮迭代修改。

## 核心能力

- 自然语言生成应用，输入"做一个贪吃蛇"即可生成完整可玩的小游戏
- 实时可视化预览，生成结果直接在右侧 iframe 中运行
- 多轮迭代，生成后可以继续对话修改，预览实时更新
- 模型调用走 Atoms Cloud 服务端，密钥不暴露在前端

## 已验证类型

贪吃蛇、五子棋、BMI 计算器、按钮交互组件

## 技术实现

- 平台：Atoms（atoms.dev）
- 模型：deepseek-v4-flash（Atoms Cloud 内置）
- 生成产物：单文件 HTML，包含所有 CSS 和 JS
- 部署：Atoms 一键发布
